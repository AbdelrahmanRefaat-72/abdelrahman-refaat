            [//] تحدي الفحص والاختبار
            
تحدي صائد الثغرات: هل تستطيع كشف العيب؟

            
الكود التالي به خطأ حدودي شائع (Boundary / Off-by-one Error). اضغط على السطر المصاب لاكتشاف الثغرة وتأكيد حسك التفتيشي!

          


          

            
1def validate_discount(cart_total, discount_code):

            
2    # Valid cart total must be greater than zero

            
3    if cart_total <= 0: return False

            
4    if discount_code == "VIP100" and cart_total > 100:  # boundary defect

            
5        return apply_discount(cart_total, percent=15)

            
6    return cart_total

          


          

            [DEFECT FOUND]
            

              تم كشف العيب بنجاح (Off-By-One Boundary Bug)
              
عندما تكون السلة بقيمة 100 بالظبط، سيفشل الشرط ويُحرم العميل من الخصم المستحق. هذا هو جوهر الـ Boundary Value Testing!

            

          

        


        
        

          

            [BVA]
            
تحليل قيم الحدود (Boundary Value Analysis)

            
التركيز على نقاط الانهيار الكلاسيكية: 0، القيمة العظمى، ما دونها وما فوقها، والقيم السالبة وغير المتوقعة.

          

          

            [EP]
            
تقسيم التكافؤ (Equivalence Partitioning)

            
تصنيف المدخلات إلى فئات صالحة وغير صالحة لتغطية أعلى نسبة اختبار بأقل عدد من الحالات دون تكرار عشوائي.

          

          

            [DEFECT]
            
تقارير عيوب واضحة (Defect Lifecycle)

            
كتابة تقرير Bug مهني يحتوي على: خطوات إعادة الإنتاج، النتيجة المتوقعة، النتيجة الفعلية، وسجلات الأخطاء للوصول للحل فوراً.

          

          

            [PYTEST]
            
أتمتة الفحص (Pytest & Postman)

            
كتابة اختبارات آلية للـ Endpoints والتحقق من صحة كود الاستجابة (Status Codes)، الـ Headers، وصحة هيكل JSON الراجع.
